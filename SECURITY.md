# Sicherheitsmeldungen

Melde eine Schwachstelle über **Security → Report a vulnerability**. Falls die Schaltfläche fehlt, bitte in einem Issue lediglich darum, den privaten Meldeweg zu aktivieren. Technische Einzelheiten gehören in die private Meldung. [Private Meldung öffnen](https://github.com/PaddyBlanco/VSC-SQL-Toolbelt/security/advisories/new)

Nenne Version, betroffene Funktion und beobachtetes Verhalten. Erstelle das Beispiel mit einer fiktiven Datenbank. Entferne Zugangsdaten, Verbindungsprofile, Hostnamen, IP-Adressen, Firmen- und Kundennamen sowie interne SQL-Definitionen aus Anhängen und Beispielen. Auch ein Screenshot vom Explorer oder eine Commit-E-Mail kann die Organisation identifizieren.

Falls ein echter Zugangswert öffentlich wurde, widerrufe oder rotiere ihn beim Aussteller sofort. Teile für die Bereinigung nur die betroffene Stelle und den Commit mit. Frühere Commits, Wiki-Versionen, Releases und Kopien können den ursprünglichen Inhalt weiterhin enthalten. [GitHub-Anleitung zur Bereinigung](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)
